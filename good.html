인증 테스트 설정

Supabase 프로젝트 URL과 공개 publishable 키만 입력하세요. secret·service_role·Google Client Secret은 입력하지 마세요. 값은 현재 브라우저에 보관되고 백업에는 포함되지 않습니다.

현재 페이지의 주소(쿼리·해시 제외)를 Supabase의 Redirect URLs에 등록하세요. Google OAuth 동의 화면과 제공자 설정이 먼저 필요합니다.

애플 건강 연동은 별도의 아이폰 테스트 앱에서 권한 요청 후 읽습니다. 이 웹 페이지와의 데이터 전송·동기화는 아직 연결하지 않았습니다.

데이터 백업

물·커피·기분·즐겨찾기를 JSON 파일 하나로 내보냅니다.

이 파일은 암호화되지 않습니다. 기분 리뷰 등 개인 기록이 포함되므로 공개 GitHub에 올리지 말고 개인 파일 보관함에 저장하세요. 수면·체성분·주기는 아직 기록 기능이 없어 포함되지 않습니다.

백업 파일 다시 다운로드

다운로드가 시작돼도 실제 파일 저장 완료 여부는 확인할 수 없습니다. 사파리 다운로드 목록 또는 파일 앱에서 저장된 JSON 파일을 확인하세요. 자동 백업·기기 동기화·백업 파일 복원 기능은 아직 제공하지 않습니다.

보관 방식과 시제품의 범위

기록은 이 주소를 연 현재 브라우저의 저장소에만 보관됩니다. 서버 전송·기기 간 동기화·외부 인공지능 분석은 하지 않습니다. 개인정보 보호 모드나 브라우저 데이터 삭제 시 기록이 사라질 수 있고, 다른 주소나 기기에서는 기록이 공유되지 않습니다.

건강앱은 미연결입니다. 음료 데이터는 사용자 제공 시트의 2026-11-08 가져온 저장본만 사용합니다. 이전 이미지 전사·검색 영양정보는 메뉴에서 제거했습니다. 시트의 이후 수정은 자동 반영되지 않습니다. 과거 섭취 기록은 삭제하지 않고 별도로 구분합니다.

전일 비교는 현재까지 입력한 기록과 어제 전체 기록을 비교합니다. 커피 건수는 기록 횟수이며, 기분·몸은 날짜별 마지막 표정 선택(1~5단계) 기준입니다. 변화는 건강 평가가 아닙니다.

기록된 섭취만 보여줍니다 · 건강 상태를 진단하거나 안전한 섭취량을 판정하지 않습니다
