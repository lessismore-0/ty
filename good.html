커피 기록

기록을 누르면 수정할 수 있고, 오른쪽 ‘삭제’로 바로 지울 수 있어요. 첫 화면의 카페인은 건강앱에 카페인 기록이 있으면 건강앱 값을, 없으면 여기의 직접 기록을 사용하며 두 값을 더하지 않습니다.

수면

점수는 시간(70점) + 연속성(30점)으로 계산한 자체 참고 지표이며 의학적 평가가 아닙니다. 겹친 구간은 한 번만 계산하고, 저녁 6시 이후에 시작한 잠은 다음 날 기록으로 묶습니다.

체성분

로그인 후 서버에서 불러온 측정 기록을 표시합니다.

주기

건강앱 월경 기록으로 다음 예정일을 계산합니다. 기록이 쌓일수록 예측이 안정되며, 피임·진단 목적이 아닙니다.

구글 로그인

로그인하면 아이폰 앱이 서버에 올린 건강앱 기록(물·카페인·탄단지·수면·체성분·주기)을 이 화면에서 조회합니다. 이 웹 페이지는 서버에 기록을 올리지 않으며, 커피·기분 기록은 이 브라우저에만 남습니다. 로그아웃해도 이 브라우저의 기록은 남으므로 공용 기기에서는 주의하세요.

인증 설정 안 됨

인증 설정

Supabase 프로젝트 URL과 공개 publishable 키만 입력하세요. secret·service_role·Google Client Secret은 입력하지 마세요. 값은 현재 브라우저에 보관되고 백업에는 포함되지 않습니다.

현재 페이지의 주소(쿼리·해시 제외)를 Supabase의 Redirect URLs에 등록하세요.

데이터 백업

커피·기분·즐겨찾기를 JSON 파일 하나로 내보냅니다. 건강앱에서 오는 기록과 로그인 토큰은 넣지 않습니다.

이 파일은 암호화되지 않습니다. 기분 리뷰 등 개인 기록이 포함되므로 공개 GitHub에 올리지 말고 개인 보관함에 저장하세요. 폰을 바꾸거나 사파리 저장소가 지워지면 커피·기분 기록은 이 파일이 유일한 사본입니다.

백업 파일 다시 다운로드

백업 파일 불러오기

같은 기록은 건너뛰고 없는 기록만 추가하며, 지금 있는 기록을 지우지 않습니다.

다운로드가 시작돼도 실제 저장 완료 여부는 확인할 수 없습니다. 사파리 다운로드 목록이나 파일 앱에서 JSON 파일을 확인하세요.

보관 방식과 범위

커피·기분·즐겨찾기 기록은 이 주소를 연 현재 브라우저의 저장소에만 보관됩니다. 서버로 보내지 않고, 외부 인공지능 분석도 하지 않습니다. 개인정보 보호 모드나 브라우저 데이터 삭제 시 기록이 사라질 수 있고, 다른 기기와 공유되지 않습니다.

건강앱 기록은 아이폰 앱이 서버로 보낸 것을 로그인 후 조회해 화면에만 표시하며, 로그아웃하면 지웁니다. 음료 데이터는 사용자 제공 시트의 2026-11-08 저장본만 사용하며, 시트의 이후 수정은 자동 반영되지 않습니다.

동기화 상태

아이폰 앱이 건강앱을 읽어 서버로 보내고, 이 화면은 서버 기록을 조회합니다. 첫 화면의 ‘동기화’를 누르면 앱이 바로 열리고, 이 화면으로 돌아오면 서버 기록을 자동으로 다시 불러옵니다.

아이폰에서 good day 앱이 열립니다. 앱에서 ‘지금 새로 조회하여 동기화’를 누른 뒤 이 화면으로 돌아오세요.

로그인 후 서버 수신 상태를 확인하세요.

순서

1. 아이폰 good day 앱에서 건강앱 읽기 허용

2. 앱에서 같은 구글 계정으로 로그인하고 업로드에 동의

3. 앱의 ‘지금 새로 조회하여 동기화’ 실행

4. 이 웹 화면으로 돌아오면 자동으로 불러옵니다. 안 보이면 ‘서버의 최신 건강 기록 불러오기’

사파리에서는 건강앱을 직접 읽을 수 없습니다. 앱을 닫아둔 동안의 자동 전송은 아직 지원하지 않습니다.
