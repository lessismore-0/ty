인증 설정

Supabase 프로젝트 URL과 공개 publishable 키만 입력하세요. secret·service_role·Google Client Secret은 입력하지 마세요. 값은 현재 브라우저에 보관되고 백업에는 포함되지 않습니다.

현재 페이지의 주소(쿼리·해시 제외)를 Supabase의 Redirect URLs에 등록하세요. Google OAuth 동의 화면과 제공자 설정이 먼저 필요합니다.

애플 건강 기록은 아이폰 good day 앱이 권한을 받아 읽고 서버로 보냅니다. 이 웹 페이지는 같은 계정으로 서버에 저장된 기록을 조회만 합니다.

데이터 백업

커피·기분·즐겨찾기를 JSON 파일 하나로 내보냅니다.

건강앱에서 오는 물·카페인·영양·수면·체성분·주기는 백업에 넣지 않습니다. 원본이 건강앱과 서버에 있어 이 파일이 없어도 다시 불러올 수 있기 때문입니다. 로그인 토큰도 넣지 않습니다.

이 파일은 암호화되지 않습니다. 기분 리뷰 등 개인 기록이 포함되므로 공개 GitHub에 올리지 말고 개인 파일 보관함에 저장하세요. 폰을 바꾸거나 사파리 저장소가 지워지면 커피·기분 기록은 이 파일이 유일한 사본입니다.

백업 파일 다시 다운로드

백업 파일 불러오기

내보낸 JSON 파일을 골라 커피·기분·즐겨찾기를 되살립니다. 같은 기록은 건너뛰고 없는 기록만 추가하며, 지금 있는 기록을 지우지 않습니다.

다운로드가 시작돼도 실제 파일 저장 완료 여부는 확인할 수 없습니다. 사파리 다운로드 목록 또는 파일 앱에서 저장된 JSON 파일을 확인하세요. 자동 백업은 아직 제공하지 않습니다. 불러오기는 같은 브라우저에서 직접 파일을 고를 때만 동작합니다.

보관 방식과 시제품의 범위

커피·기분·즐겨찾기 기록은 이 주소를 연 현재 브라우저의 저장소에만 보관됩니다. 이 기록은 서버로 보내지 않고, 외부 인공지능 분석도 하지 않습니다. 개인정보 보호 모드나 브라우저 데이터 삭제 시 기록이 사라질 수 있고, 다른 주소나 기기에서는 공유되지 않습니다.

건강앱 기록(물·카페인·탄단지·수면·체성분·주기)은 아이폰 앱이 서버로 보낸 것을 로그인 후 조회해 화면에만 표시하며, 로그아웃하면 지웁니다. 음료 데이터는 사용자 제공 시트의 2026-11-08 가져온 저장본만 사용합니다. 시트의 이후 수정은 자동 반영되지 않습니다. 과거 섭취 기록은 삭제하지 않고 별도로 구분합니다.

전일 비교는 현재까지의 기록과 어제 전체 기록을 비교합니다. 기분·몸은 날짜별 마지막 표정 선택(1~5단계) 기준입니다. 변화는 건강 평가가 아닙니다.

카페인 한도 400 mg은 성인 일반 권고 기준입니다 · 임신 중이면 300 mg 이하가 권고됩니다 · 이 화면은 기록을 보여줄 뿐 건강 상태를 진단하지 않습니다
